# 社区指南

欢迎加入 Lucide 社区！本指南提供了有关如何参与、贡献以及与其他 Lucide 社区成员联系的信息。

## 行为准则

请阅读并遵守我们的 [行为准则](/code-of-conduct.md)，以确保为所有社区成员提供一个欢迎和包容的环境。

## 与社区联系

有多种方式可以参与 Lucide 社区：

- **加入 Discord 服务器**：在我们的 [Discord 服务器](https://discord.gg/EH6nSts) 上与其他 Lucide 用户联系、提问并分享您的项目。
- **在 X 上关注我们**：通过在 [X](https://x.com/lucide_icons) 上关注我们，随时了解最新新闻和更新。
- **加入 GitHub 讨论**：在我们的 [GitHub 讨论页面](https://github.com/lucide-icons/lucide/discussions) 上参与讨论、提供反馈并帮助他人。

## 参与贡献

- **为项目做贡献**：查看我们的 [贡献指南](./contribute/index.md)，了解如何为 Lucide 项目做出贡献。
- **报告问题**：如果您遇到任何错误或有任何功能请求，请在我们的 [GitHub 问题页面](https://github.com/lucide-icons/lucide/issues) 上报告。

## 您可以做什么

有很多方式可以为 Lucide 社区做出贡献。

### 帮助他人

代码或新图标形式的贡献总是受欢迎的，但您也可以通过在 Discord 或 GitHub 讨论区回答其他社区成员的问题来提供帮助。

### 设计新图标

如果您有设计技能，请考虑为 Lucide 库贡献新图标。查看我们的 [图标设计指南](/contribute/icon-design-guide.md)，获取创建符合 Lucide 风格图标的提示和指南。

### 贡献代码

如果您是开发人员，您可以为 Lucide 项目贡献代码。无论是修复错误、添加新功能还是改进文档，您的贡献都是有价值的。查看我们的 [贡献指南](/contribute/index.md) 以获取更多信息。

### 问题分类

您可以通过审查和分类我们 GitHub 仓库中的问题来提供帮助。这包括确认错误、提供额外信息以及帮助维护者确定问题的优先级。

### 改进文档

Lucide 的文档开放贡献。如果您发现任何可以改进的地方，或者有关于新指南或教程的想法，请随时提交 pull request。

文档可以在 [仓库](https://github.com/lucide-icons/lucide/tree/main/docs) 中找到。

### 分享您的经验

分享您在项目中使用 Lucide 的经验。撰写博客文章、创建教程或在社交媒体上分享您的项目，以帮助他人发现并了解 Lucide。
