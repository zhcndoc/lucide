# 隐私声明

_最后更新：2026 年 10 月 27 日_

Lucide 是一个开源项目。我们创建 lucide.dev 时尽可能少收集有关你的信息：目标是尽可能减少个人数据的收集。我们不会出售你的个人数据，浏览网站也无需注册账号。本页面说明你访问网站时会发生什么，以及原因。

本声明仅适用于 **lucide.dev**。我们的周边商店（merch.lucide.dev）、GitHub、Discord、Open Collective 以及其他链接网站均有各自的隐私政策。

## 责任方

lucide.dev 由位于荷兰的 Lucide Icons 运营。如对本声明或你的数据有疑问，请通过 [info@lucide.dev](mailto:info@lucide.dev) 联系我们。

## 收集哪些数据及原因

### 托管

网站托管在 [Vercel](https://vercel.com/legal/privacy-policy) 上。与其他 Web 服务器一样，Vercel 会处理你的 IP 地址、浏览器 User-Agent 和你请求的页面，以便提供网站并防止滥用。这些日志会保存 1 天，不会用于分析你的个人特征。

### 分析

我们使用注重隐私保护的分析服务，了解哪些页面和图标更受欢迎，以便确定改进方向。我们在自己的子域名（insights.lucide.dev）上运行 **OpenPanel**，收集的数据存储在欧盟境内。它会统计页面浏览量和网站使用情况：复制或在 Lucide Studio 中打开了哪些图标、何时开始搜索图标、图标自定义器和排序设置的变化、主页按钮和软件包的点击情况，以及页面滚动深度。

OpenPanel 不会设置 Cookie，也不会在你的浏览器中存储任何内容。除上述事件外，它还会记录来源网站、浏览器类型、设备类型和国家等一般信息。访问量通过临时匿名标识符统计，该标识符无法用于在其他网站或之后的日期识别你。我们不会追踪外链点击，也不会将这些数据与其他来源的数据合并。

### 搜索

站内搜索由 [Algolia DocSearch](https://www.algolia.com/policies/privacy/) 提供。使用搜索框时，你输入的内容和 IP 地址会发送给 Algolia 以返回搜索结果。最近的搜索记录保存在你的浏览器中（见下文）。

### 广告

部分页面会展示一则由 [Carbon Ads](https://www.carbonads.net/privacy)（BuySellAds）提供的广告。广告收入用于支持项目开发。广告根据页面内容选择，不会根据你的兴趣或浏览历史投放。为了展示广告、统计展示量和点击量并防止欺诈，Carbon 会收到你的 IP 地址（用于估算所在国家）及基本浏览器信息。Carbon 的隐私政策说明了其处理这些数据的方式。

### 第三方图片

贡献者和团队成员头像直接从 GitHub 加载，因此加载图片时 GitHub 会收到你的 IP 地址。请参阅 [GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)。

软件包页面上的版本和下载量徽章从 [Shields.io](https://shields.io) 加载，因此加载图片时 Shields.io 会收到你的 IP 地址。

## Cookie 和浏览器存储

lucide.dev 不会自行使用追踪或广告 Cookie。

| 内容 | 类型 | 用途 | 时长 |
| --- | --- | --- | --- |
| 部署版本（`__vdpl`） | Cookie（Vercel） | 网站更新期间让你继续使用同一版本，避免访问过程中页面出错 | 会话期间 |
| 图标自定义设置 | 本地存储 | 记住你选择的尺寸、描边宽度、颜色和描边缩放设置 | 直到你清除 |
| 外观 | 本地存储 | 记住浅色或深色模式 | 直到你清除 |
| 框架选择 | 本地存储 | 记住你正在阅读哪个框架的文档 | 直到你清除 |
| 最近搜索和收藏搜索 | 本地存储 | 在搜索框中显示这些记录 | 直到你清除 |

这些内容是你所用功能正常运行所必需的，或用于保存你主动做出的选择。它们不会离开你的浏览器，你可以随时在浏览器设置中清除。

## 法律依据

我们基于合法利益处理这些数据（GDPR 第 6 条第 1 款第 f 项），以运营快速、安全且可持续的网站：托管和保护网站、了解网站的使用情况，并通过非追踪广告为项目提供资金。我们只保留必要的最少数据，并避免识别单个访客。

## 国际传输

Vercel、Algolia、Carbon Ads、GitHub 和 Shields.io 可能会在欧洲经济区以外（包括美国）处理数据。发生这种情况时，这些服务商会依靠欧盟—美国数据隐私框架或欧盟委员会标准合同条款等保障措施。

## 你的权利

根据 GDPR，你有权访问、更正或删除个人数据，有权限制或反对对数据的处理，也有权要求数据可携带。由于我们不会将分析数据关联到具体个人，通常无法查找专属于你的数据，但我们愿意提供帮助。请通过 [info@lucide.dev](mailto:info@lucide.dev) 联系我们。

你还有权向数据保护机构提出投诉。在荷兰，该机构为 [Autoriteit Persoonsgegevens](https://autoriteitpersoonsgegevens.nl)。

## 变更

如果我们添加新服务或更改数据处理方式，会更新本页面及顶部日期。你可以在我们的 [GitHub 仓库](https://github.com/lucide-icons/lucide/commits/main/docs/privacy.md)查看本页面的完整历史记录。
