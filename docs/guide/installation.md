# 安装

## Web

Lucide 图标库在 Web 应用程序中的实现。

::: code-group

```sh [pnpm]
pnpm add lucide@next
```

```sh [yarn]
yarn add lucide@next
```

```sh [npm]
npm install lucide@next
```

```sh [bun]
bun add lucide@next
```

:::

更多详情，请参阅 [文档](./lucide/index.md)。

## 静态用法

Lucide 图标库的实现，适用于多种用法，例如：SVG 文件图标、SVG 精灵图、图标字体以及在 Common JS 模块中导出的静态 SVG 字符串（适用于 NodeJS）。

::: code-group

```sh [pnpm]
pnpm add lucide-static@next
```

```sh [yarn]
yarn add lucide-static@next
```

```sh [npm]
npm install lucide-static@next
```

```sh [bun]
bun add lucide-static@next
```

:::

更多详情，请参阅 [文档](./static/index.md)。
