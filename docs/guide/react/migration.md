# 从 v0 迁移

品牌图标在 v1 中已被移除。如果您正在使用以下任何图标，则需要将它们替换为自定义 SVG 或替代图标：

- Chromium
- Codepen
- Codesandbox
- Dribbble
- Facebook
- Figma
- Framer
- Github
- Gitlab
- Instagram
- LinkedIn
- Pocket
- RailSymbol（基于英国铁路标志）
- Slack

我们建议使用各品牌提供的官方 SVG 图标，其中大多数可以在它们的网站或品牌指南中找到。或者，您可以使用 [Simple Icons](https://simpleicons.org/) 中的图标，该网站提供了大量的品牌图标集合，同时也包含指向官方品牌指南和 SVG 图标的链接。
