# Inkscape 设置指南

本指南介绍如何为 Lucide 图标设置 Inkscape。

## 设置画布

Inkscape 会使用默认画布尺寸创建新文档。将其更改为 `24 × 24` 像素：

1. 使用 `文件 > 文档属性` 打开文档属性对话框。
2. 在 _页面尺寸_ 选项卡中，在 _自定义尺寸_ 下，将单位设置为 `px`，并将宽度和高度设置为 `24`。
   ![设置页面尺寸](../../images/page-size.png?raw=true '设置页面尺寸')
3. 在 _网格_ 选项卡中，选择 `矩形网格`，然后点击 _新建网格_。
   ![设置网格属性](../../images/grid-1.png?raw=true '设置网格属性')
4. 将网格单位设置为 `px`，然后将 `间距 X` 和 `间距 Y` 设置为 `1`。
   ![设置网格属性](../../images/grid-2.png?raw=true '设置网格属性')
5. 关闭文档属性对话框。
6. 要使画布居中显示在视口中，请选择 `视图 > 缩放 > 绘图`。

## 设置路径

1. 创建路径或形状。
2. 选中路径后，按下 `Ctrl+Shift+F` 打开描边和填充面板。
   ![描边样式属性](../../images/strokes.png?raw=true '设置网格属性')
3. 在 _描边样式_ 选项卡中：
   - 将描边宽度设置为 `2px`。
   - 选择圆角连接类型。
   - 选择圆角端点类型。
4. 对于矩形，选择矩形，然后在工具栏中将 `Rx` 和 `Ry` 设置为 `2px`。
   ![矩形半径属性](../../images/corner-radius.png?raw=true '矩形半径属性')

## 保存文件

1. 准备就绪后，点击 _另存为_，并选择 _优化的 SVG_ 作为文件类型。
   ![另存为](../../images/save-as.png?raw=true '另存为')

## 优化图标

最后一步是使用 [Lucide Studio](https://studio.lucide.dev/) 优化 SVG。
