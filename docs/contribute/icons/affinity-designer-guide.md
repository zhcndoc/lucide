# Affinity Designer 模板指南

本指南介绍如何使用 Lucide 的 Affinity Designer 模板

## 工作流程

> Affinity Designer 默认使用点作为描边单位。在绘制之前，将描边更改为像素。打开 `Preferences > User Interface`，然后在 `Decimal Places for Unit Types` 下取消选中 `Show Lines in points`

1. 下载并打开 [Affinity Designer 模板](https://github.com/lucide-icons/lucide/blob/main/docs/public/templates/affinity_designer.aftemplate)
2. 在设计图标时遵循[设计语言](design-principles.md)
3. 使用 `File > Export` 将文件导出为 SVG。将栅格化设置为 _Nothing_，选中 _Export text as curves_、_Use hex colors_ 和 _Flatten transforms_

   ![Affinity Designer 中的 SVG 导出选项](../../images/affinity-designer-export-options.png?raw=true)
