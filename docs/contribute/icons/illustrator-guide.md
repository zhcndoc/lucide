# Adobe Illustrator 模板指南

本指南介绍如何使用 Adobe Illustrator 的 Lucide 模板。

> 模板可能会过时。开始之前请查看[设计语言](design-principles.md)。

## 工作流程

Illustrator 模板遵循[设计语言](design-principles.md)。

1. 下载并打开 [Illustrator 模板](https://github.com/lucide-icons/lucide/blob/main/docs/public/templates/illustrator_template.ai)。

2. 移除示例徽标图层（`Draw`）中的内容，然后开始绘制。

3. 检查你的图标是否遵循[设计语言](design-principles.md)。

4. 导出之前，移除不必要的图层，尤其是 `Padding` 和 `Grid`。

5. 使用 `Export > Export As...` 导出文件，然后将其保存为 SVG。使用以下 SVG 选项：

   ![Illustrator 中的 SVG 导出选项](../../images/illustrator-svg-options.png?raw=true 'Illustrator 中的 SVG 导出选项')

6. 使用 [Lucide Studio](https://studio.lucide.dev/) 优化你的 SVG
